# Contributors of XAL, XALC and XVM

This file lists people who take part in the project. Names will appear here as the project grows.

How to add yourself: append one line in the same form as below and send
it with your change. One line per person: name - contact - area.

```
<num> Your Name - https://github.com/<name> - area: XAL, XALC, XVM, docs, tests
```

Areas cheat sheet:
- XAL   - the language itself, syntax and semantics.
- XALC  - the compiler, program xal.
- XVM   - the virtual machine, program xvm.
- docs  - documentation in doc/ru and doc/en.
- tests - tests and examples.
