Глава 2. Лексика - из чего состоит текст программы

2.1 Комментарии

Комментарии пишутся двумя способами - решеткой или двойным слешем.
Все до конца строки игнорируется:

  # это комментарий
  // это тоже комментарий
  print("привет"); # комментарий после кода

Вложенных или многострочных комментариев нет. Не нужно - и так хорошо.

2.2 Имена

Имя начинается с буквы или подчеркивания, дальше могут идти буквы,
цифры и подчеркивания. Примеры нормальных имен: schetchik, x2, _tmp,
MOY_SPISOK. Регистр важен: schetchik и Schetchik - два разных имени.

Имена из модулей складываются через точку, например lib.answer. Точка
внутри имени - единственное исключение, про модули рассказано в главе 7.

2.3 Ключевые слова

Вот полный список слов, которые заняты языком и не могут быть именами:

  fn let if else while for return break continue
  true false nil and or not use in
  module import pub case default

Их всего 22, запоминаются быстро, потому что почти все они -
уже знакомые по другим языкам управляющие конструкции.

2.4 Числа

Числа в XAL - только целые. Десятичные пишутся как обычно, а
шестнадцатеричные - с приставкой 0x:

  let a = 42;
  let b = 0xFF; # то же, что 255

Вещественных чисел нет. Отрицательные пишутся через минус перед
числом: -5. Это не часть числа, а операция отрицания, но работают они
так, как все привыкли.

2.5 Строки

Строки берутся в двойные или одиночные кавычки - разницы нет:

  let s1 = "привет";
  let s2 = 'и тебе привет';

Внутри работают экраны: \n перевод строки, \t табуляция, \r возврат
каретки, \0 нулевой символ, \\ сам слеш, \" и \' кавычки. Любая другая
буква после слеша означает саму себя: \d это просто d.

Строка может занимать несколько строк текста - перевод строки просто войдет
в нее как есть. А вот забытые закрывающие кавычки компилятор не простит:
получишь ошибку "unterminated string literal".

2.6 Знаки препинания в коде

Двухсимвольных операций всего одиннадцать:

  == != <= >= && || += -= *= /= ..

Все остальное - одиночные знаки: + - * / % < > = ! ( ) { } [ ] , ; . и так
далее. Пробелы, табуляции и переводы строк важны только как разделители:
можно писать все в одну строку или растягивать на сотню, это дело вкуса.
