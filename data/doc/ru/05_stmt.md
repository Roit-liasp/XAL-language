Глава 5. Операторы

5.1 Let и присваивание

Новая переменная создается словом let:

  let age = 30;
  let name; # без значения - будет 0

Повторное let с тем же именем не ошибка - просто положит новое значение
в ту же переменную. Присваивание уже существующей переменной идет
без let:

  age = 31;

Есть короткие формы: += -= *= /=. Запись "x += 2" означает "x = x + 2".
А вот формы для остатка или склейки нет - пиши полностью.

Элемент списка меняется по индексу:

  l[0] = "новое";

Индексов может быть сколько угодно - вложенные списки меняются так же:

  m[0][1] = "новое";
  l[0] += 2;          // короткие формы работают и по индексу

Если индекс дальше конца списка, список вырастет, а появившиеся дыры
заполнятся нулями. Присваивание по индексу строки молча игнорируется:
строки меняют только целиком.

5.2 If и else

Условие - любое выражение, скобки не обязательны:

  if vozrast >= 18 {
      print("вход разрешен");
  } else {
      print("приходи позже");
  }

Цепочки делаются через else if - сколько угодно:

  if bally > 90 { print("отлично"); }
  else if bally > 70 { print("хорошо"); }
  else { print("можно лучше"); }

Правда и ложь для условий определены в теме 3.2: ноль, пустая строка
и пустой список считаются ложью.

5.3 Case

Case - это аккуратный выбор из нескольких вариантов без лесов из if:

  case den_nedeli {
      1, 2, 3, 4, 5 { print("будни"); }
      6, 7 { print("выходные"); }
      default { print("такого дня нет"); }
  }

Выражение после case сравнивается с каждым значением через ==.
В одной ветке можно перечислить несколько значений через запятую.
Ветка default необязательна - если ее нет и ничего не подошло, просто
ничего не произойдет.

5.4 While

Цикл "пока условие истинно":

  let i = 0;
  while i < 5 {
      print(i);
      i += 1;
  }

Если условие ложно сразу - тело не выполнится ни разу. Забытый счетчик
даст бесконечный цикл, так что не забывай менять то, что проверяешь.

5.5 For

For проходит по списку или по строке:

  for name in ["Anna", "Bob", "Kim"] {
      print("привет, " .. name);
  }

  for letter in "кот" {
      print(letter); # "к", потом "о", потом "т"
  }

Переменная цикла каждый раз получает следующий элемент. Пустой
список или пустая строка - тело не выполнится ни разу. Выйти досрочно
можно через break, пропускать виток - через continue.

5.6 Break, continue, return

Три слова для управления потоком:

- break - немедленно выйти из ближайшего while или for.
- continue - бросить текущий виток и перейти к следующему.
- return - вернуться из функции, возможно со значением.

Пример:

  for x in data {
      if x < 0 { continue; }
      if x == 0 { break; }
      print(x);
  }

Return без значения возвращает 0. Break и continue вне цикла -
ошибка компиляции, компилятор сразу скажет.

5.7 Блоки и точка с запятой

Фигурные скобки группируют операторы в блок:

  {
      let v = 1;
      print(v);
  }

Важно: блок НЕ прячет переменные. Все let внутри функции видны во всей
функции, даже если объявлены глубоко внутри блоков. Скобки - просто способ
сказать "это вместе", а не новая область видимости.

Точка с запятой после операторов необязательна. Можно писать с ней,
можно без - делай как удобно. Пустой оператор из одной точки с запятой
тоже разрешен и ничего не делает.
