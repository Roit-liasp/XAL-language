Глава 3. Типы данных

3.1 Всего три типа

В XAL нет десятков типов, от которых болит голова. Их ровно три:

- int - целое число. Примеры: 0, 42, -7.
- str - строка. Примеры: "привет", "".
- list - список. Это упорядоченный набор любых значений, даже
  смешанных: [1, "два", [3]].

Типы указывать не нужно - переменная просто хранит то, что в нее положили.
Сегодня там число, завтра строка, языку все равно.

Слова true, false и nil - это не отдельные типы. True превращается
в 1, а false и nil - в 0. Удобно: можно писать понятно, а внутри все равно
живут обычные числа.

3.2 Что считается правдой

В условиях if, while, а также в and, or и not работает простое правило:

- число 0 - ложь, любое другое число - истина;
- пустая строка "" - ложь, не пустая - истина;
- пустой список [] - ложь, список с элементами - истина.

Поэтому можно писать так, и все будет работать как ждут:

  if name { print("имя введено"); }
  while jobs { work(); }

3.3 Как значения превращаются друг в друга

Две встроенные функции делают это явно:

- str(x) - превращает что угодно в строку. Список станет
  чем-то вроде "[1, два]".
- int(x) - превращает в число. Строка парсится как число ("42" даст 42,
  а "мусор" даст 0), список даст свою длину.

А есть места, где превращение случается само. Плюс склеит строки, если
хотя бы один из операндов - строка. Сравнения == и != сравнят как текст,
если хотя бы один операнд - строка. Порядок (<, > и друзья) всегда
сравнивает числа. Подробности - в главе 4.
