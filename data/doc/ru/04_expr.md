Глава 4. Выражения

4.1 Порядок действий

Операции в XAL идут от слабой к сильной связи в таком порядке:

1. или: ||, or
2. и: &&, and
3. сравнения: == != < <= > >=
4. сложение и склейка: + - ..
5. умножение: * / %
6. первичное: числа, строки, скобки, вызовы, индексы, not, минус

Словами and, or и not можно писать буквами - для тех, кто не любит
значки. Скобки работают как везде и спасают, когда порядок неочевиден:

  let x = (a + b) * c;
  if (age > 18) and pass { enter(); }

4.2 Арифметика и склеивание строк

Пять операций: + - * / %. Деление целочисленное: 7 / 2 даст 3.
Остаток: 7 % 2 даст 1. Унарный минус меняет знак: -x.

Два важных сюрприза, оба приятные:

- Деление и остаток на ноль не роняют программу, а дают 0. Не надо
  спросить почему - так решили авторы, чтобы скрипты не падали.
- Плюс умеет клеить строки: "кот" + "опес" даст "котопес". Если хотя бы
  один операнд - строка, второй молча превратится в строку тоже.

А точки ".." - это честная склейка всегда: переведут в строку оба
операнда и склеят. Когда хочется именно склейки, а не арифметики,
пиши две точки:

  let s = "ответ: " .. 42; # "ответ: 42"

4.3 Сравнения

Все шесть как обычно: == != < <= > >=. Результат всегда 1 или 0.

Тонкий момент: == и != смотрят на типы. Если хотя бы один операнд -
строка, сравнение идет по тексту. Значит "42" == 42 это истина, потому что
число 42 превратится в строку "42". Порядок - <, >, <=, >= - такой же:
если хотя бы один операнд строка, сравниваются строки, то есть "10" < "9"
это истина (по алфавиту, а не по числу). Числа с числами сравниваются
численно.

  if answer == "да" { print("согласен"); }
  if height > 170 { print("высокий"); }

4.4 Логика - and, or, not

Три операции над правдой и ложью:

- a and b (или a && b) - истина, если оба истинны.
- a or b (или a || b) - истина, если хотя бы один истинен.
- not a - переворот: из истины делает ложь и наоборот.

And и or ленивые: второй операнд вычисляется только если первого не хватило
для ответа. Поэтому так писать безопасно:

  if item and item[0] == "start" { print("поехали"); }

Здесь item[0] никогда не тронут, если список пуст - ошибки не будет.

Честное предупреждение для любопытных: как значения and и or
возвращают не всегда 1 и 0. And возвращает второй операнд, если первый
истинен, иначе 0. Or возвращает 1, если первый истинен, иначе второй
операнд. В условиях это не видно, но в арифметике лучше на это
не полагаться.

И еще: not и унарный минус привязаны очень крепко, только к следующему
значению. Запись "not a == b" читается как "(not a) == b", а не как
"not (a == b)". Хочешь отрицать все сравнение - ставь скобки.

4.5 Вызовы функций в выражениях

Вызов - это имя и скобки с аргументами:

  let d = length("привет");
  print(add(2, 3), "готово");

Аргументов может быть от нуля до 32. Вызовы можно вкладывать друг в друга
сколько угодно. Свои функции от встроенных по виду не отличить - и это
хорошо, меньше запоминать.

4.6 Списки и квадратные скобки

Список создается квадратными скобками:

  let empty = [];
  let mixed = [1, "два", [3, 4]];

Индексы считаются с нуля. У списков они возвращают элемент, у строк -
символ как строку из одного символа:

  let l = ["a", "b", "c"];
  print(l[0], l[2]); # "a" "c"
  let s = "привет";
  print(s[1]); # "р" - вторая буква

Скобки можно ставить цепочкой: matritsa[1][0] возьмет нулевой элемент
первого списка. Выход за границы не роняет программу: у списков получишь 0,
у строк - пустую строку. Удобно для скриптов, где лучше пустота, чем
падение.
