Глава 6. Функции

6.1 Как объявить функцию

Функция начинается со слова fn, дальше имя, скобки с параметрами
и тело в фигурных скобках:

  fn add(a, b) {
      return a + b;
  }

Параметров может не быть вовсе:

  fn greet() {
      print("hello");
  }

Слово pub перед fn нужно для модулей - оно делает функцию видимой
снаружи. Про это подробно в главе 7.

6.2 Аргументы и возвращаемое значение

Вызов передает аргументы по порядку:

  let s = add(2, 3); # 5

Язык не ругается на неверное число аргументов. Что не передали
станет нулем, что передали лишнее - тихо выкинется. Удобно для
скриптов, но иногда прячет опечатки, так что будьте внимательны.
Максимум - 32 аргумента в одном вызове, больше компилятор не даст.

Return отдает значение наружу. Если функция дошла до конца без
return - вернется 0. Так что любая функция всегда что-то
возвращает, хотя бы ноль.

Функцию можно вызвать раньше, чем она объявлена в файле, - компилятор
сперва собирает все имена, а уже потом проверяет. А вот вызов
несуществующей функции он найдет и откажется собирать программу.
Две функции с одним именем - тоже ошибка.

6.3 Main и код вне функций

Функция main - точка входа, она обязательна. Без нее компилятор
скажет "no main function" и остановится.

Код, написанный просто в файле вне функций, тоже не теряется: он
собирается в скрытую служебную функцию init и выполняется перед
main. Это удобное место для начальных значений:

  let factor = 10; # выполнится до main

  fn main() {
      print(5 * factor);
  }

Глобальные let могут стоять и до, и после функций - порядок не важен,
все они выполнятся до старта main в порядке написания.

6.4 Где видны переменные

Правила простые:

- Переменная, объявленная внутри функции, - локальная. Она живет только в этой функции и видна во всем ее теле, даже внутри вложенных блоков.
- Переменная вне функций - глобальная. Ее видят все функции.
- Присваивание внутри функции имени, которое есть среди глобальных, меняет именно глобальную. Если такого имени нигде нет - создастся новая локальная.

И главная ловушка для новичков: чтение несуществующей
переменной - не ошибка. Язык тихо создаст глобальную со значением 0
и пойдет дальше. Опечатка в имени даст ноль вместо ругани. Если программа
ведет себя странно - первым делом проверяй имена.
